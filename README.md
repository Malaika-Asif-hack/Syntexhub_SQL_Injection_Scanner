# SQL Injection Scanner - Syntexhub Internship Project

## Description
Automated SQL Injection vulnerability scanner for educational purposes. Tests web applications for error-based, time-based, and boolean-based SQL injection vulnerabilities.

## Features
- ✅ Error-based SQL injection detection
- ✅ Time-based blind SQL injection detection  
- ✅ Boolean-based blind SQL injection detection
- ✅ Form parameter scanning (GET/POST)
- ✅ URL parameter scanning
- ✅ Website crawling (optional)
- ✅ Multi-threaded scanning
- ✅ Rate limiting (ethical scanning)
- ✅ JSON report generation
- ✅ Detailed logging
- ✅ Target whitelist (ethical compliance)
